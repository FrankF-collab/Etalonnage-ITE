# ITE

Application autonome (PWA) pour la fiche de maintenance du CdV à ITE : fonctionne hors ligne, données stockées sur l'appareil.

## Publier sur GitHub Pages
1. Créer un dépôt GitHub (ex. `ITE`), y déposer tous les fichiers de ce dossier (Add file > Upload files).
2. Settings > Pages > Source : *Deploy from a branch*, branche `main`, dossier `/ (root)`.
3. Ouvrir `https://<utilisateur>.github.io/ITE/` sur le téléphone, puis *Ajouter à l'écran d'accueil*.
